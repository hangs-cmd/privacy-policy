# LumaBeat 개인정보처리방침

최종 업데이트: 2026년 5월 20일 · 시행일: 2026년 5월 20일

LumaBeat("앱")는 스마트폰 카메라를 이용해 심박수(BPM), HRV, 신호 품질 등 웰니스 참고 지표를 제공하는 앱입니다. 본 개인정보처리방침은 앱이 어떤 정보를 처리하는지, 그 정보를 어떻게 사용하고 보호하는지, 사용자가 보유한 권리는 무엇인지 설명합니다.

본 앱은 의료기기가 아니며, 측정 결과는 의학적 진단·치료·질병 예방·응급 판단을 대체하지 않습니다. 건강 문제가 있거나 측정 결과가 걱정되는 경우 의료 전문가와 상담하시기 바랍니다.

## 1. 처리하는 정보

### 카메라 데이터

앱은 전면 카메라를 사용해 얼굴의 미세한 색상 변화를 실시간 분석합니다. 카메라 영상, 사진, 얼굴 이미지는 **앱에서 저장하지 않으며 외부로 전송되지 않습니다**. 카메라 입력은 심박수 등 웰니스 지표 계산을 위해 기기 내에서만 처리됩니다.

### 건강 및 웰니스 측정 데이터 (기기 내 저장)

앱은 사용자의 측정 이력을 표시하기 위해 다음 데이터를 **기기에 저장**합니다.

- 심박수(BPM)
- HRV 관련 지표(SDNN, RMSSD, pNN50, LF/HF, 호흡수 등)
- 신호 품질 지수(SQI 및 4성분: SNR, IBI 규칙성, 스펙트럼 순도, 진폭 안정성)
- 측정 시각, 측정 소요 시간
- PPG 파형, IBI 시계열, FFT 스펙트럼 등 분석용 데이터
- 조명 환경(normal/dim/bright/warm/cool) 및 측정 품질 관련 정보

이 데이터는 의료 기록이 아니며, 앱 내 참고용 이력과 차트 표시를 위해 사용됩니다.

### 설정 및 앱 사용 데이터

앱은 언어 설정, 온보딩 완료 여부, 알림 설정, 데이터 공유 동의 상태 등 앱 사용에 필요한 설정값을 기기에 저장합니다.

### 광고 및 제3자 SDK 데이터

앱은 광고 제공과 동의 관리를 위해 Google AdMob, Google User Messaging Platform 등 제3자 SDK를 사용합니다. 이 과정에서 기기 식별자, 광고 식별자, 대략적인 위치, 광고 상호작용 정보 등이 각 SDK 제공자의 정책에 따라 처리될 수 있습니다.

앱은 건강 측정 데이터를 맞춤 광고 목적으로 판매하거나 공유하지 않습니다.

## 2. 정보 사용 목적

- 카메라 기반 웰니스 측정 기능 제공
- 심박수, HRV, 신호 품질 등 결과 계산
- 측정 이력, 차트, 상세 분석 표시
- 앱 설정 저장
- 사용자가 명시 동의(Opt-in)한 경우에 한해 익명 측정 데이터를 클라우드에 전송하여 알고리즘 개선
- 광고 표시 및 개인정보 선택 관리
- 앱 안정성 개선 및 원격 설정 관리

## 3. 클라우드 전송 (Opt-in)

**기본 설정에서는 건강 측정 데이터가 기기 안에만 저장되며 외부로 전송되지 않습니다.**

앱 내 **설정 → 데이터 공유** 화면에서 사용자가 다음 항목을 개별적으로 켤 수 있습니다.

| 토글 | 전송처 | 전송 항목 |
|------|--------|-----------|
| 사용 통계 공유 (Analytics) | Google Firebase | 측정 시작/완료/중단 이벤트, BPM/SQI 버킷, 조명 환경, 광고 노출 이벤트, 익명 instance id |
| 측정 품질 진단 공유 (Health Diagnostics) | Supabase | BPM, HRV, SQI, 조명 환경, 디바이스 모델군, 익명 install_id 등 |
| 오류 보고 공유 (Crashlytics) | Google Firebase | 크래시 스택 트레이스, 측정 단계, 디바이스 모델군, 익명 install_id |

업로드 시 디바이스 식별자(IMEI, 광고 ID, 시리얼)는 일절 전송하지 않으며, 디바이스 모델·OS 정보는 재식별을 방지하기 위해 거친 단위로 버킷팅됩니다.

각 토글은 언제든 끌 수 있으며, 끄면 이후 신규 데이터 전송이 즉시 중단됩니다.

### Tier 3 — 원시 신호 신고 (별도 동의)

측정 결과 화면의 **"측정 결과가 부정확한가요?"** 버튼을 누르면 별도 동의 dialog가 표시됩니다. 사용자가 명시 동의한 경우에만 그 측정에 한해 PPG 파형(15초 분량), FFT 스펙트럼, IBI 시계열이 Supabase Storage로 전송됩니다.

신고하지 않으면 원시 신호는 일절 전송되지 않습니다.

| 이전 거부 권리 | 동의는 언제든 데이터 공유 화면에서 회수 가능. 회수 후 신규 업로드 중단 |

## 5. 보관 및 삭제

- 기기 내 측정 이력은 사용자가 앱 데이터를 삭제하거나 앱을 제거할 때 삭제됩니다.
- 클라우드로 업로드된 익명 데이터는 앱 내 **설정 → 데이터 공유 → "내 클라우드 데이터 삭제"** 버튼으로 즉시 모두 삭제할 수 있습니다. 동시에 새로운 익명 ID가 발급되어 이전 기록과의 연결이 끊깁니다.

## 6. 만 14세 미만 아동

LumaBeat는 만 14세 미만 아동을 대상으로 하지 않으며, 의도적으로 만 14세 미만 아동의 개인정보를 수집하지 않습니다. 만 14세 미만 아동의 개인정보가 수집된 사실을 확인한 경우 즉시 삭제합니다.

## 7. 정보주체의 권리

사용자는 다음 권리를 행사할 수 있습니다.

- 개인정보 처리에 대한 동의 철회 (설정 → 데이터 공유)
- 클라우드 데이터의 즉시 삭제 (설정 → 데이터 공유 → "내 클라우드 데이터 삭제")
- 처리 정지·이의 제기 및 열람 요청 (아래 문의처)

## 8. 보안

LumaBeat는 사용자 데이터를 보호하기 위해 기기 내 저장, HTTPS/TLS 1.2 이상 암호화 전송, 클라우드 측 Row Level Security(RLS) 정책, 익명 식별자 사용 등 합리적인 기술적·관리적 조치를 적용합니다. 다만 인터넷 전송 또는 전자 저장 방식이 완전히 안전하다고 보장할 수는 없습니다.

## 9. 개인정보처리방침 변경

본 방침은 앱 기능, 법령, 스토어 정책 변경에 따라 수정될 수 있습니다. 중요한 변경이 있는 경우 시행일 14일 전부터 앱 내 공지 또는 본 페이지를 통해 안내합니다.
