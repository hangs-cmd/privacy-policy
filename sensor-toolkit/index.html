개인정보처리방침

Sensor Toolkit  ·  최종 수정일: 2025년 5월 7일

Sensor Toolkit(이하 "앱")은 이용자의 개인정보를 소중히 여깁니다. 본 방침은 앱이 어떤 정보를 수집하고 어떻게 사용하는지 설명합니다.

1. 수집하는 권한 및 사용 목적

권한사용 도구사용 목적서버 전송
마이크
RECORD_AUDIO		 소음계 주변 소음 데시벨 측정. 오디오는 기기 내에서만 분석되며 녹음·저장되지 않습니다. 없음
위치
ACCESS_COARSE_LOCATION
ACCESS_FINE_LOCATION		 나침반, 방위계 기기 방위 측정에 OS가 요구하는 권한. 위치 좌표는 앱이 사용·저장·전송하지 않습니다. 없음
모션 센서 수평계, 진동계, 자기장계 가속도·자기장 데이터를 실시간으로 화면에 표시. 서버로 전송되지 않습니다. 없음
진동
VIBRATE		 전체 (햅틱) 사용자 동작에 대한 촉각 피드백. 없음
저장소
WRITE_EXTERNAL_STORAGE		 소음계, 진동계 측정 그래프 이미지를 기기 갤러리에 저장. Android 9 이하에서만 필요합니다. 없음
화면 활성화
WAKE_LOCK		 전체 측정 중 화면이 꺼지지 않도록 유지. 없음

2. 자동 수집 정보 (제3자 SDK)

Firebase Analytics / Crashlytics / Performance (Google LLC)

  • 앱 충돌 보고, 익명 사용 이벤트, 성능 지표를 수집합니다.
  • 이름·이메일·전화번호 등 개인 식별 정보는 수집하지 않습니다.
  • 데이터는 Google 서버에 전송됩니다. Google 개인정보처리방침 →

Google AdMob / UMP (Google LLC)

  • 앱 무료 제공을 위해 광고를 표시합니다. 측정 화면 내부에는 광고가 없습니다.
  • 광고 개인화 여부는 최초 실행 시 사용자가 선택합니다 (GDPR/ATT 동의).
  • AdMob은 기기 광고 ID, 일반 기기 정보를 사용할 수 있습니다. AdMob 정책 →

3. 데이터 보관 및 삭제

앱이 기기 내에 저장하는 데이터:

  • 측정 기록 (로컬 DB) — 앱 삭제 시 함께 삭제됩니다.
  • 설정값 (언어, 캘리브레이션 배율 등) — 앱 삭제 시 함께 삭제됩니다.

서버에 개인 데이터를 보관하지 않으므로 별도 서버 삭제 절차는 없습니다. 추가 요청은 아래 이메일로 연락해 주세요.

4. 어린이 개인정보

본 앱은 13세 미만 어린이를 대상으로 하지 않으며, 어린이의 개인정보를 의도적으로 수집하지 않습니다.

5. 방침 변경

본 방침은 변경될 수 있습니다. 중요 변경 시 앱 업데이트 노트로 안내하며, 이 페이지의 최종 수정일을 갱신합니다.
